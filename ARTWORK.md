Generated with the built-in Imagegen tool for this project. Reference: the user-supplied golden-hour voxel workshop.

Web versions preserve alpha and use WebP quality 94. Independent CSS breathing, steam, sleep marks, pet response and bounded pointer depth provide the scene animation. These are layered raster sprites, not rigged 3D models. Reduced-motion and pause controls are included.
