# The Golden Hour Workshop

Kerem Can's interactive project room. A buildless, responsive site for GitHub Pages.

The room is an optimized WebP illustration with lightweight CSS ambient effects and accessible project hotspots. All six projects remain accessible through the project drawer. Includes keyboard navigation, native modal focus handling, an evening light mode, and reduced-motion support.

Run locally with any static HTTP server, for example `python -m http.server 4173`.

Publish the main branch root with GitHub Pages. No build step or API keys required.
